# Sessão: Configuração Caddy + Acesso Mobile
**Data:** 2026-04-08

---

## 🎯 Objetivo

Configurar Caddy como reverse proxy para testar o Workout Tracker no celular via rede local, usando Supabase Local.

---

## ✅ O que foi feito

### 1. Arquivos Criados

| Arquivo | Descrição |
|---------|-----------|
| `Caddyfile` | Config principal - proxy localhost:3000 → 3001 |
| `Caddyfile.mobile` | Config para rede local - IP 192.168.0.180:3000 → 3001 |
| `Caddyfile.preview` | Config para build estático - localhost:8080 |
| `CADDY.md` | Guia completo de uso do Caddy |

### 2. Arquivos Modificados

| Arquivo | Mudança |
|---------|---------|
| `package.json` | Scripts adicionados: `dev:mobile`, `dev:mobile:caddy`, `dev:caddy`, `preview:caddy` |
| `supabase/config.toml` | `api_url` alterado de `127.0.0.1` para `192.168.0.180`, `site_url` e `additional_redirect_urls` atualizados |
| `.env` | `SUPABASE_URL` alterado de `http://127.0.0.1:54321` para `http://192.168.0.180:54321` |
| `.gitignore` | Adicionado `caddy_data/` e `caddy_config/` |

### 3. Configurações do Supabase

```toml
# supabase/config.toml
[studio]
api_url = "http://192.168.0.180"

[auth]
site_url = "http://192.168.0.180:3001"
additional_redirect_urls = [
  "https://192.168.0.180:3001",
  "http://192.168.0.180:3001",
  "http://192.168.0.180:3000",
  "https://192.168.0.180:3000"
]
```

### 4. IP da Rede Local

```
IP do PC: 192.168.0.180
```

## 🚀 Como Usar

### No Celular (Rede Local)

```bash
# 1. Se Supabase local não estiver rodando:
npm run db:start

# 2. Iniciar app + Caddy:
npm run dev:mobile:caddy
# OU manualmente (2 terminais):
npm run dev:mobile                    # Terminal 1
caddy run --config Caddyfile.mobile   # Terminal 2 (como Admin)

# 3. No celular, acessar:
http://192.168.0.180:3000
```

### Dev Local (Desktop)

```bash
npm run dev          # localhost:3000
npm run dev:caddy    # Com Caddy proxy
```

### Preview Estático

```bash
npm run preview:caddy   # Build + Caddy em localhost:8080
```

---

## ⚠️ Notas Importantes

1. **Supabase Local está em uso** - dados isolados do cloud
2. **Celular e PC devem estar no mesmo WiFi**
3. **Firewall do Windows** pode precisar de exceção para portas 3000/3001/54321
4. **IP pode mudar** - se mudar, atualizar:
   - `.env` (SUPABASE_URL)
   - `Caddyfile.mobile`
   - `supabase/config.toml` (api_url, site_url, additional_redirect_urls)
5. **Caddy precisa de Admin** no Windows para instalar certificados TLS
